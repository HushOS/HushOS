HushOS push relay

This service wakes the HushOS apps on iPhone and Android when something happens in an account, such as a new sign-in or a file shared with you. Apple and Google deliver notifications to an app only from its publisher, so hushos.com and every self-hosted HushOS server send their pings for phones through here.

What a push carries

An event id and a short tag, nothing else. Never what happened, who it involves or a file name. The app fetches the event from its own server over its own connection and writes the notification itself. Apple and Google see only that a device got a push, and when.

What this service keeps

  • For each phone: the push token Apple or Google gave it, the platform, and SHA-256 digests of the random handle and deletion secret it was handed. No account, email, name or server address.
  • No timestamps, and no record of which server pinged which phone. Its logs are hourly counts.
  • For rate limits only, the addresses that sent pings in the last hour, in memory.

It learns that a handle got a ping, from a server's address, at a time, and whether it was a security notice. A token Apple or Google report dead is deleted with every handle that uses it.

Running your own HushOS server?

Your server sends pings here for phones signed in to it. To send none, set PUSH_RELAY_URL to an empty value: the apps then show notifications only while they are open. Browsers never need this service; your server pushes to them directly.
